# Setup-tool

A Termux/Linux package installer tool that helps you easily install commonly used development and utility packages.

## Features
- Interactive package selection
- Progress indicator for installations
- Logging of installation process
- Support for multimedia tools (ffmpeg, imagemagick) useful for social media content creation

## Usage
```bash
bash setup_tool.sh
```

## Available Packages
- git, curl, wget - Development tools
- nano, vim - Text editors
- python, nodejs, ruby, php - Programming languages
- ffmpeg, imagemagick - Multimedia processing tools (useful for video/image editing for social media)
- And more...
